Apis to create the project:-

1) Signup
------------
  To signup the page of ecommerce
  firstly we do signup usign two methods:-

   endpoint: POST api/auth/signup

    1.1) Using email or password
        ->Using name, email, password, role as a field.
        ->Role is in enum either seller or user

        Request Body                                   
            {
             "method" : "email",
             "name" : "Bhoomi",
             "email" : "xyz@gmail.com",
             "password" : "######",
             "role":"user"
            }

           Backend Logic:-
                ->Validate required fields
                ->Check if email already exists
                ->Hash password using BCrypt
                ->Save user in DB
                ->Generate and return JWT token


       Response Body
           {
           success:true,
           status_code:200,
           message:"Signup successfully",
           data:[
               "id":"1",
               "name":"Bhoomi",
               "email":"xyz@gmail.com",
               "role":"user",
               "access_token": "<ACCESS_TOKEN>",
               "refresh_token": "<REFRESH_TOKEN>"
               ]
           }

   
      1.2)Using phone number or otp
         
         ->In the otp case , firstly request otp for phone signup
            endpoint: POST api/auth/request-otp
            
            Request
                {
                 "phoneNumber":"+91XXXXXXXXXX"
                }

            Backend Logic:-
                ->Validate phone format
                ->Generate 6-digit OTP
                ->Save OTP in database (with expiry time)
                ->Log OTP in console (not SMS)


            In console :
            Generated OTP for phone no is: XXXXXX
             
            Response 
                {
                  "message":"otp sent to console"
                }
         
         **Then signup using phone + otp**
           enpoint: POST api/auth/signup

           Request
               {
                "method":"phone",
                "name": "Bhoomi",
                "phoneNumber": "+91XXXXXXXXX",
                "otp": "XXXXXX",
                "role": "seller"
               }

           Backend Logic:-
             ->Verify OTP from database
             ->Check if phone number already registered
             ->Save user (no password)
             ->Generate and return JWT token

             Response
                {
                   success:true,
                   status_code:200,
                   message:"Signup successfully",
                   data:[
                       "id":"1",
                       "name":"Bhoomi",
                       "phone":"+91XXXXXXXXXX",
                       "role":"seller",
                      "access_token": "<ACCESS_TOKEN>",
                      "refresh_token": "<REFRESH_TOKEN>"
                        ]
                }

        2.3)Logout 
        ---------
        endpoint: POST api/auth/logout
        ->Blacklist the token, one way is to use tokenversion
        ->tokenversion can be update to invalidate the token
       

        2.4)Forgot_password
        ------------------
        endpoint: POST api/auth/forgot_password

        ->User click on forgot password button, then user entered the mail then mail checks on DB it exist or not,
        ->If it exist, then link is formed with (https://your-website.com/reset-password?token=<token>&email=user@example.com),
        ->Then this token, mail, expiry minutes is saved in DB,
        ->When the authenticated user click on this link, then token is comes with in link,
        ->Then user enetered the password, the password is save in database, through this token the mail if find and the hashed password is save in db
